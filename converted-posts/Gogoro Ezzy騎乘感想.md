<!-- wp:paragraph -->
<p>2025/12/6牽的Gogoro Ezzy到現在差不多滿3個月，可以來分享一下心得，讓想買電動機車的人參考一下，首先來簡介一下這台車。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Gogoro Ezzy是單電池版本，如果你要雙電池請買Gogoro Ezzy 500，外型長得一樣，只是500沒有灰色，Ezzy的售價是差不多6萬台幣，由於有一台油車可以汰舊換新政府補助，可以補助26300元。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>目前騎起來跟當初設定的需求實際上是蠻符合的。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>由於本身騎油車20年，在沒買這台車之前也有騎過gogoro的電動車，所以可以說一下油車跟電車自身感受的差別。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>1.<mark style="background-color:rgba(0, 0, 0, 0);color:#f30505" class="has-inline-color">等紅綠燈時</mark>，電車基本上就像油車熄火的狀態，完全沒聲音沒震動，這時旁邊如果剛好停一台比較老舊的油車，聲音嘟嘟嘟的抖動，紅綠燈的秒數一久就可以感受到，那到底是什麼東西？而且排氣管不斷冒出白煙製造環境污染，電車可是連排氣管都沒有啊</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>2.這台<mark style="background-color:rgba(0, 0, 0, 0);color:#f63c04" class="has-inline-color">輪轂馬達</mark>騎起來幾乎安靜無聲，只有低速時會有嘟嘟警示音，其他比較早期的Gogoro騎起來也會有電動馬達或齒輪聲，油車在剛買時其實引擎聲也不會大到哪裡去，但只要到達一定年限，那引擎的嘈雜聲肯定跟新車相去甚遠。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>3.<mark style="background-color:rgba(0, 0, 0, 0);color:#f93c02" class="has-inline-color">加速</mark>：順間加速的力道不如油車，就連我之前騎過雙電池版的Gogoro也是一樣，想要跟油車競速的話還是別買電車吧，但，本人沒那個需求，安全第一。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>4.<mark style="background-color:rgba(0, 0, 0, 0);color:#f73c04" class="has-inline-color">換電池v.s加油</mark>，油車加一次油可以騎個一個禮拜不是問題，同樣里程下電車可能1,2天就要換一次電，但換電其實整個過程不用30秒，就抽出來放回去而已，油車還要加油，刷信用卡等等..，這點換電的方便性是遠高於油車，覺得想要更久換一次電，或距離騎得更遠的話就買雙電池版本，但我當初設定就是在住家附近騎而已所以只需要單電池就夠啦，另外就是加油站通常人會比較多，而電車因為數量遠低於油車，大部分的時間你去換電除非是尖峰時間否則基本上只有你一個人，也不會需要排隊。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>5.<mark style="background-color:rgba(0, 0, 0, 0);color:#f93c02" class="has-inline-color">保養</mark>：油車1000公里要去換機油齒輪油，電車5000公里在保養就好，有的gogoro是3000，無論如何這點還是方便太多，gogoro新車有2年保固，保固期間除了耗材外都免費更換，目前我是還沒有去保養過，所以不知道實際上的花費到底如何。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>6.<mark style="background-color:rgba(0, 0, 0, 0);color:#fa3b01" class="has-inline-color">機車行v.s Gogoro維修據點</mark>，本人超級不喜歡去機車行維修機車，原因是有很多不老實的店家會趁機敲竹槓，或懶的叫料用一些店裡現有但不是那麼適合的東西和你說這也可以裝到機車上之類的，而且通常只有一個人在修，gogoro的站點我去的時候是有三個技師，可能是因為據點比較少的緣故吧。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>7.<mark style="background-color:rgba(0, 0, 0, 0);color:#f93c02" class="has-inline-color">資費</mark>：一個月429可以騎565安時，你可以想像成一安時接近一公里，我自己的感覺差不多是這樣啦，就順順的騎沒有激烈操駕，官方宣稱可騎7.800公里那是在定速30km的情況下啦，可以騎600多就不錯了，當然也有吃到飽的方案，可是那是騙你的，只有離峰時段才能換電，超過1600安時連續兩個月就會把你退出方案了。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><mark style="background-color:rgba(0, 0, 0, 0);color:#2102f7" class="has-inline-color">Ｑ＆Ａ</mark>：<mark style="background-color:rgba(0, 0, 0, 0);color:#f73a00" class="has-inline-color">有沒有遇到故障或換到沒電的電池</mark>？</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>目前有大概三次，換完電池發不動的狀況，但是把電池重新更換就又可以發動了，所以這或許是電池的問題......？<mark style="background-color:rgba(0, 0, 0, 0);color:#f60616" class="has-inline-color">目前為止，不論任何時段，</mark><mark style="background-color:rgba(0, 0, 0, 0);color:#2104fe" class="has-inline-color">從來沒有在換電站換到未滿格的電池</mark><mark style="background-color:rgba(0, 0, 0, 0);color:#f60616" class="has-inline-color">，加上之前騎雙電池兩個月，總共騎5個月電車，一次都沒有</mark>。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>對了，我的新車在騎沒多久時就有出現異音，時不時的會在低速時出現，去問技師也說螺絲都鎖緊了，但不影響騎乘所以就算了吧。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>倒車功能超推薦，可以在取車時超方便，停進去停車格直接一鍵輸出！</p>
<!-- /wp:paragraph -->
